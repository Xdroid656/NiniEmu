# NiniEmu
Open-source reimplementation of the Entis GLS, Malie, NeXas and Escude visual novel engines.

# ReadMe

An unofficial, open-source player for visual novels made with the
Entis GLS, Malie, NeXas and Escude engines. It reads the game's own
files and runs the game's own scripts, so the text, effects, menus
and saves are the game's own.

**Status:** early. See CHANGELOG.md and docs/todo.md.

You need your own installed copy of the game. This project contains
no game data.

## Supported engines

| Engine    | Status      |
|-----------|-------------|
| Entis GLS | In progress |
| Malie     | Planned     |
| NeXas     | Planned     |
| Escude    | Planned     |
